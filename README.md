# GymBruh

GymBruh is an AI-powered fitness companion built to bring workout planning, nutrition tracking, daily habits, and personal fitness guidance into one place.

Instead of treating fitness as just a workout tracker, GymBruh combines planning, tracking, and AI-assisted guidance into a single dashboard.

## What it does

- Personalized onboarding and fitness setup
- AI-powered workout planning
- AI Trainer for fitness-related conversations
- Food scanning and nutrition analysis
- AI-assisted meal and nutrition planning
- Sleep tracking
- Hydration and daily habit tracking
- Fitness journal
- Progress and activity dashboard
- Nutritionist-related guidance
- Supabase authentication and data storage

## Tech Stack

- Next.js
- TypeScript
- React
- Supabase
- Google Generative AI
- CSS
- Vercel
